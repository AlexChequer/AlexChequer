## 🚀 Featured Projects

### [Image Colorization](https://github.com/hhenriqueN/image-colorization)
Deep learning pipeline that colorizes black and white images by predicting the `a, b` chrominance channels in LAB color space from luminance. Three training phases of increasing quality: a U-Net baseline trained from scratch, a ResNet-34 encoder + U-Net decoder with perceptual loss, and a conditional GAN with a PatchGAN discriminator for vivid, locally realistic outputs. Built in PyTorch, trained on ~93K images from Open Images V7.

### [Store Platform — Microservices](https://github.com/Microservice-Alex-Carlos-Lucas/microservices)
E-commerce platform built with a microservices architecture (Gateway, Auth, Account, Product, Order, Exchange) deployed on AWS EKS with Postgres on RDS and Redis. Includes infrastructure-as-code, CI/CD with Jenkins, load testing, and bottleneck analysis. Coursework for *Platforms, Microservices, DevOps and APIs* at Insper.
